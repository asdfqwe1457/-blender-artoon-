三渲二原创角色学习路线图：从零基础到独立成品的必经之路
三渲二原创角色看起来门槛不高：模型可以简化，材质偏纯色，描边也有现成工具。但真正从零走到独立成片，难点不在某个单点技术，而在学习顺序和取舍。下面按五个阶段给出一条可执行的路线，每个阶段都标出目标、练习方式和常见误区。

第一阶段：美术基础与软件入门，约四到六周。零基础不要一上来就做角色，先解决三件事：剪影、比例、色块。每天用简单几何体画十张剪影小稿，练习概括形体；同时熟悉 Blender 的基础操作，包括视图导航、物体模式与编辑模式、修改器、材质面板和渲染设置。这个阶段的目标不是做出成品，而是能独立完成一个简单静物：建低模、展 UV、给纯色材质、用 EEVEE 渲染出图。常见误区是跳过剪影直接抠五官，结果转面就崩。三渲二角色的识别度首先来自轮廓，其次才是细节。

第二阶段：建模与 UV，约四到六周。重点学卡通角色的拓扑逻辑：头部用环线支撑表情，身体保持大块面，衣服褶皱只做三到四条主折，头发做成大块面而不是细发丝。练习方法是先临摹一个简单卡通角色，从 Blockout 到低模再到 UV 完整走一遍。UV 不追求高像素密度，但要保证色块边缘干净，按皮肤、衣服、头发、道具分组。这个阶段要开始用简单骨骼测试关节活动，避免肩甲、裙摆、袖口在动画时穿插。常见误区是建模阶段堆太多碎细节，三渲二着色后阴影会断成噪点，反而难看出手绘感。

第三阶段：三渲二着色与描边，约四到六周。这是三渲二的核心。先理解明暗色阶：用 Shader to RGB 把灯光信息转成阶梯色，再用 Color Ramp 控制两到三层明暗，材质保持接近纯色，只加轻微渐变和手绘笔触。描边先用 Freestyle 做外轮廓，学会用线条集和边缘标记关掉内部多余线条，线宽按镜头距离微调。练习做三个小测试：同一角色分别用两级、三级、四级色阶渲染，对比哪一版更接近目标动画；给描边加粗细变化；测试运动镜头下描边是否闪烁。常见误区是材质纹理加得太多，画面像写实角色套了描边，失去三渲二的平面感。

第四阶段：绑定、动画与渲染合成，约四到六周。学基础人形骨骼、手指简化绑定和形态键表情，做走路、坐下、拿道具三个动作。三渲二动画要注意节奏：预备和跟随可以略夸张，但明暗分界要清晰。渲染用 EEVEE，关闭软阴影，保留硬边阴影更接近二维动画。分层输出角色色块、描边、背景和发光件，合成时描边层用正片叠底，色块层加轻微纸张纹理。常见误区是灯光打得太复杂，三渲二不需要多灯，主光加补光就够，关键是让明暗分层稳定。

第五阶段：完整项目实战，约六到八周。选一个原创短篇角色，从概念小稿、建模、UV、材质、绑定、动画到成片完整走一遍。项目开始前先做一张目标画面的色彩小稿，把明暗层数、描边粗细和材质对比定下来，后面所有环节围绕这张小稿走。每周做一次自检：剪影是否清楚、色块是否干净、描边是否稳定、动作是否可信。成片输出后做三版对比，找出问题再迭代。

整条路线大约五到七个月，关键不是学完所有功能，而是按“剪影—建模—色阶—描边—成片”的顺序推进，每个阶段只解决一个核心问题。零基础最容易犯的错是同时学建模、材质、动画和合成，结果每样都停在半路。先把一个简单角色完整做出来，再回头补细节，进步会快得多。
